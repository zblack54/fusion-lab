Precision and interpretation

Displayed values come from the recorded CSV (12 decimal places), not unrounded internal estimator state. Charts use a bounded subset of actual samples; the cursor can inspect every row. A missing measurement is absent, never substituted with zero. Truth is used for inspection/error calculation only, never fed into the estimator.

Local verification diagnostics

Bounded local observations, with no telemetry. Timing separates event timestamp, handler entry, draw completion and the next animation-frame opportunity. That opportunity is a presentation proxy, not proof of physical display. Unsupported browser metrics are unavailable. Native renderer RSS is measured separately.
