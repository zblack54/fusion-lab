Projection accepts duration and borrowed Sample rows, not a Config. Its result owns copied identities/timestamps/measurements. All replay/model types have private fields and read-only accessors; ReplayModel contains only requested sigma/q. The constructor signatures contain no truth, trajectory, RNG seed or source-estimate reference. This API structure prevents accidental ongoing borrowing of source truth into the replay owner.

Its positive offline locked check must pass before replacing only consumer source with eight record-update attempts and requiring exact type-specificE0451diagnostics. It never scans or falls back to cached rlibs. Both command results and diagnostics are retained in the raw native proof. This negative check proves no externally unrestricted record update, not by itself that every internal field is private. Exact-source inspection of every field and alternate constructor/trait remains required.

The current seam is a compile diagnostic, not an implementation to inspect for successful projection. This is the design argument and executable oracle plan; main independent review and implementation-stage inspection are reserved. No code-behavior acceptance is claimed.
