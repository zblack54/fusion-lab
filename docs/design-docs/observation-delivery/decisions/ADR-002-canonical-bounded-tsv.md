# ADR-002 canonical-bounded-tsv

Status: selected for draft design under main preparation authority; final contract approval pending.

Options were newJSONdependencies, permissiveplotCSV or strict versionedround-tripTSV. The draft selects stdlibTSV with three model lines, canonicalDisplaybits, exact integer/header/order validation and bounded buffers. Negative consequence: genericspreadsheet spellings/CRLF/alternatefloattext are rejected. The valid-domain1053bytecombinedheader counterexample caused a preapprovalsplit into three lines, preserving1024linecap. Revisit for a new schema, never reinterpretversion1. AffectedREQ024–028;CON004;MOD003; codec/golden/extreme tests.
