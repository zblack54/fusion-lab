# Intent and authority

Issue69 is the pure synchronous prerequisite for parent6 and later22/8. The researcher can project exactly the source observations, replay an explicit planned-delivery trace under OnTimeOnly, inspect every loss/stale/horizon decision, and regenerate canonical artifacts without scheduling changing physics.

Main selected the API and resource/format boundaries for formal design preparation in issue69comment6501213904. That authorizes this draft and its minimal diagnostic compile seam only. It does not approve implementation, a final contract lock, or product acceptance. This package remains draft/ai_ready=false. Main independently reviews executable oracles, full native evidence and non-test arguments before external approval/locking.

The numerical core remains synchronous. Actual asynchronous channels, slow-consumer cancellation/shutdown, historical correction, EKF, sensor changes, paid APIs, deployment and service/dashboard wire migration are out of scope. Parent6 remains open after the eventual pure first slice. Existing observation streams, default run/CLI CSV and previously accepted adapter contracts remain obligations.

The baseline is the immutable target_revision in spec.toml. Only src/delivery.rs and src/lib.rs exports are diagnostic production changes. Every callable stub reaches one named not-implemented panic; no fixture branch or partial delivery implementation is present.
