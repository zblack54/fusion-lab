# Terms
Recorded row: original rounded CSV sample, not a reconstructed latent filter state.
Plotted row: selected actual recorded index, at most4096 per trace.
Cursor row: any exact recorded sample selected independently from plot density.
Live status: service lifecycle SSE; not live per-tick numerical telemetry.
Reachable storage bound: application-owned typed numeric buffers, not an OS memory limit.
Unsigned wire integer: validated decimal token retained without JavaScript Number rounding.
