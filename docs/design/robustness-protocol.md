# Noise mismatch and constant bias: proposed held-out protocol

Status: DRAFT for issue #21; no experiments collected under this protocol. Depends on accepted constant-bias slice of #20 and merged #19. Drift is excluded and remains a separate #20 follow-up. Main approval and independent review must freeze the protocol before execution.

## Question and fixed workload

Measure how fixed velocity bias and assumed measurement noise affect position error and nominal uncertainty coverage through a position outage. This is an evaluation of these specific simulation assumptions, not a calibration certificate or recommendation to tune R.

Use seeds 1000 through 1031 inclusive, deliberately disjoint from demonstrations 7, 42, 314159 and existing regression seeds. Independent preflight confirmed disjointness from published outage seeds10000..10049/20000..20049, noise demonstrations7/42/314159 and regression seeds0..7/43; recheck final inventories before freezing. Every seed runs both straight and maneuver trajectories for 30 seconds, with position outage [10,20) seconds, true position sigma 2 m, true velocity sigma 0.3 m/s, q=0.1 m²/s³. Apply one common assumed sigma scale 0.5, 1, or 2 to both channels (not an independent channel cross), and cross that scale with fixed world-frame velocity offsets [0,0], [0.3,-0.15], [1,-0.5] m/s. Total 32*2*3*3=576 runs. No drift, parameter search, adaptive stopping or outcome-based exclusions. Each run has 3001 rows. Execute serially and summarize one CSV at a time; discard raw CSV only after hashed provenance and independently checked metrics are durable. Preserve failures rather than replacing seeds.

## Outcomes and comparisons

Primary outcomes per run: outage filter position RMSE and outage nominal95% joint position coverage, using all 1000 outage ticks. Secondary: whole-run filter RMSE/coverage, outage hold/integration RMSE, and paired outage RMSE differences against matched assumptions (scale1) at the same seed, trajectory and bias. Report all nine conditions for each trajectory, including negative results.

Recovery is a separately defined descriptive endpoint: first tick at or after20s for which Euclidean filter position error stays <=1m for 101 consecutive snapshots spanning exactly one second. Search candidate starts through29.00s inclusive so the full window ends by30s. Report latency from20s and unrecovered by30s explicitly; do not average only recovered runs without also giving the denominator/censoring count. This threshold is an operational convention, not a physical requirement.

Across-seed inference treats each seed as a unit, never individual temporally correlated rows. Report mean, standard deviation, minimum and maximum across32seeds; paired mean differences with Monte Carlo standard error sample_sd(differences)/sqrt(32), with sample variance denominator31. Label this simulation Monte Carlo uncertainty; avoid unsupported population confidence claims and hypothesis significance claims. Give trajectory-specific results; no pooled winner or tuning selection. Coverage uses the existing chi-square2 threshold5.991464547107979 and the full covariance submatrix, not independent per-axis bounds.

## Bounded execution and failure recovery

Each run has a60second timeout and32MiB per-run artifact cap. Execute serially, with at most two current CSVs plus one reference sidecar retained in working memory/on staging disk; compact completed metrics/hash records survive. An overall4hour wall-clock budget checkpoints incomplete work without changing the fixed inventory. Resume only missing keys after verifying unchanged protocol/source/lock/toolchain hashes. A failed key remains failed with original logs/artifact hashes; one explicitly recorded retry is permitted for transient process/I/O failure, never to replace a numerical or invariant failure. All576keys must be accounted for before a complete-study claim. No adaptive stopping based on performance, coverage or comparative outcomes.
